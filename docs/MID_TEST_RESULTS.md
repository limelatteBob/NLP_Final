### 软件组复核

测试需求指定 Cedar、Maple 两个房间、香港时区、持久化、保留取消记录，并要求通过系统创建可识别的预订。当前导出的 `exports.json` 使用 `MIDTEST-*` 人工样式 ID，代码的创建接口却生成 UUID，无法据此证明这些记录由实际业务流程产生。说明书描述 5000 端口与 `/rooms`、`/book` 等接口，代码使用 8000 端口与 `/api/*` 接口。相关差异和修订反馈均归档。

Verifier 在返修中发现并推动修复了时间格式校验错误。冻结的 `verification_check.py` SHA-256 为 `6d08044518737a29f6fd62e69c2252e96912dcc8e3b5faaefb3493373cfe2037`。原测试重跑成功，不足以替代说明书和数据真实性的人工检查。第一题保留待确认状态，第二题记录为前置阻塞。

### 新闻组复核

第一题实际澄清为主网站文章、邮件简讯和社交短文，优先 2026-08-23 至 2026-11-23 的 Clear Water Bay 事件，可考虑联合广州校区事件。Agent 没有找到足够来源，没有编造事件、引语或链接。

第二题草稿对检测器局限作出结论，但全部论证依赖一篇 Wikipedia 汇总。外部复核发现：Common Sense Media 的 20% / 10% / 7% 是青少年自报被教师错误标记的比例，不能写成实验测得的检测器误报率，更不能直接外推大学作业。[原始研究报告](https://www.commonsensemedia.org/sites/default/files/research/report/2024-the-dawn-of-the-ai-era_final-release-for-web.pdf)

草稿还把整体准确率误译为 AI 作业漏检比例，并从少数大学案例推及普遍停用。已将问题和原始报告链接通过群聊反馈；这项外部核查由测试者完成，不计作 Agent 自主研究结果。目前独立核查子任务尚未执行，不能宣称整题通过。

### 基金组复核

第一题的实际澄清明确为虚构课程人物：长期增长、10 年以上、风险偏好 6/10、有独立应急储备、不使用杠杆或衍生品。模型自行提出 85% 股票 / 15% 债券的模拟配置，并将 7.80 汇率和基金名称标为假设或占位，不声称掌握实时价格。

外部复核发现，提案将市盈率页面引用为联系汇率制度的证据；可核验制度的原始资料应来自 [香港金管局](https://www.hkma.gov.hk/eng/key-functions/money/linked-exchange-rate-system/)。再平衡示例从 90% 调回 85% 时应区分组合总值的 5% 与股票持仓的约 5.56%，同时统一“超过 5 个百分点”与“达到 5 个百分点”的触发条件。风险说明还需补充债券基金的利率、信用等风险，不能保证股票下跌时债券必然提供缓冲。[Investor.gov 债券基金风险说明](https://www.investor.gov/introduction-investing/investing-basics/glossary/bond-funds-and-income-funds)

Agent 风险审查报告仅核对已观察到的 URL 和文档结构，没有识别这些问题。人工复核反馈已写入同群记录，第一题保留待验收状态。

第二题首次完成研究和分析，但连续三次 HTML 响应超过单次 4096 token 上限而失败，未执行截断动作。改进输出预算提示后重跑；模型主动请求前次分析材料，测试者通过原任务的回答框提供前次真实生成的 `investment_analysis.md` 原文，并注明它尚未独立核验。这是显式人工澄清，不是绕过跨轮归档规则，也未手写替代投资分析。

重跑生成 `semiconductor_outlook_presentation.html`。实际采用了更紧凑的单次输出，没有调用分段 `update_file`；因此本轮只能证实预算提示后成功生成了 HTML，不能宣称已验证真实模型的分段写入。验证者编写的 Python 在 Docker 中检查只读输入并通过，随后却尝试将只读输入列为自己的交付物，被控制器拒绝；其固定 `exists` 条件又要求本地根目录同名 HTML，导致后续两次提交失败。没有为让结果通过而更改验收条件或取消输入保护。

测试者从正常团队页面下载 HTML，用独立浏览器上下文打开，验证 12 页、前后按钮、左右键和末页边界，且包含来源、投资含义和风险。下载文件 SHA-256：`85e3a7c9b96cb448d03824a21a6b4f1d52027286a98b301374021e0d6eef97c8`。页面中市场份额、价格涨幅等关键数量主张仍缺少原始来源复核，不能据交互成功认定投资分析可靠。
